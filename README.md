### 🔥 Featured Projects

#### 🦁 [Leo: The On-Device Financial Mentor](https://github.com/raythekool/edge-skill-financial-advisor)
An empathetic AI educator for the Google AI Edge Gallery. Leo runs locally on your device, tracks your financial literacy progress, awards gamified badges, and delivers dynamic macroeconomic news—all while strictly enforcing an ethical "No-Advice" rule. Built entirely in Vanilla JS for sub-95KB size and zero dependencies.

#### ⛈️ [Italian Weather Alerts (Protezione Civile)](https://github.com/raythekool/edge-skill-italian-weather-alerts)
A decentralized Edge skill that queries official Italian Civil Protection Open Data bulletins directly from your device. It maps municipalities to alert zones and renders color-coded hydrogeological warnings inside an inline mobile chat webview with zero backend servers.

#### 🚗 [AWTRIX Travel Time Display](https://github.com/raythekool/ha-awtrix-travel-time)
A modular **Home Assistant Blueprint** for showing real-time commute travel times on **AWTRIX 3** pixel displays (e.g. Ulanzi TC001). Features dynamic traffic delay color-coding (green/yellow/red), MQTT Auto-Discovery, dual daily time windows (commute to/from), and custom icons.
